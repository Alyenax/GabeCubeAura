# Development preview sources

The animations in this folder are illustrated documentation previews, not
Faceplate firmware files or footage of physical hardware. Every scene uses
front-on Steam Machine enclosure studies and the same 64 × 54 source grid.

## Current voice assistant preview

`gabecube-companion-voice.gif` is a silent 19-second documentation illustration,
640 × 800 pixels, sampled at 20 fps. Its machine uses the approved front-on
enclosure proportions, one authored RGB sample per native 64 × 54 dot and the
17-LED diffuser. Native `companion-living-turn-v2` prepared frames provide the
short appearance, attentive movement and one complete 360-degree success turn.
There is no live 3D rendering or invented rotation interpolation.

The source is the credited TUFKAC Witcher 3 Dashboard below. The pink Slow Prism
bar uses the runtime mouth renderer and envelopes from original prepared EN
speech; the final line is an actual optional personality-pack remark:
“Everything is ready. Except, perhaps, you.” These are original prepared voices,
not official Valve dialogue or a performer clone. No audio or voice model is
embedded in the public GIF.

The native bottom-row compositor shows one controller at Home and resets the
illustrated session to `0H00` when the game starts, rather than retaining the
source example's older session duration. All clock, weather and battery values
remain demonstration data.

Forty-pixel captions sit outside the native matrix. The final caption remains
visible for 10.8 seconds, including 7.6 seconds after the Dashboard returns.
Caption holds are reading time, not a claim about response speed, USB timing,
hardware optics or actual recognition. No game is launched. The documentation
GIF is not uploaded to the faceplate and is not subject to its 12,000-byte
interactive-asset budget. See `ASSISTANT_VOICE_PREVIEW.json` for timing and hash.

## Earlier timer preview

GabeCube Companion is original procedural fan art interpreting Valve's Weighted
Companion Cube. It uses the approved six-face native renderer: smooth full turns,
a six-pixel jump and two-pixel rebound. The 50-fps native animation slots are
illustrated at 25 fps here without adding source pixels or interpolated artwork.
The silent light bar visualization uses the actual runtime Slow Prism renderer
with the supplied synthesized activation motif and prepared spoken timer-confirmation
envelope. It then uses the runtime Playtime countdown renderer, not an invented
LED effect. The story starts on the approved native TW3 Dashboard, receives
“Hey Cube” and a 30-minute timer request, then returns to TW3 with LEFT 30 MIN.
The artwork uses the TUFKAC source credited above. No audio is embedded in the
public GIF, and the source sound pack has not been cleared for public distribution.
This longer demonstration intentionally shows full gestures; a real completed
command returns to normal routing without an extra decorative delay. Neither
this illustration nor the older model measures enclosure optics or USB timing.

The Detroit portrait uses the source's real animation, cropped to Chloe's face
without the cover logo. There is no artificial pan or reversed facial motion.

The weather previews also replay the project's actual 17-LED **Bluewater**
rain renderer, rather than an invented light-bar effect. Its eight-second
period and the matrix's 2.4-second period are retained in a 24-second combined
preview loop. A shared illustration timeline is not physical timing proof.

Weather scenes, matrix composition, forecast icons, typography and Gabe's
facial animation come from the project's development renderers. The silent
Gabe preview is a scripted, subtitled 24-second timer workflow: the user's
"Hey Gabe" call, the runtime's "I'm listening" greeting, a 30-minute request,
confirmation, countdown lighting and return to the animated TW3 Dashboard.
It uses a 40% mouth width, Steam-blue eyes, warm salt-and-pepper hair/beard
and champagne bronze or muted plum glasses. The 2026-10-13 approved V4 export
also supplies the hair framing and taupe beard shadow without a black cutout.
The eyebrows follow the light-brown hair strand, with the Lab 92 colour
correction applied without changing the approved geometry or animation.
Both versions use the same native prepared face as the development plugin;
only the glasses colour changes. It is not speech recognition or a real timer
activation; the thirty minutes are not compressed into the illustration.

Weather, forecast, clock, battery, performance and playtime values are
illustrative. Weather Dashboard retains its background animation beneath
the runtime compositing layer. The bar's optical blending is simulated.
