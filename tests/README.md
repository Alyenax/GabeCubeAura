# Public source test scope

These tests cover the shipped light-bar/Faceplate runtime, routing, setup, updates, packaging and licensing. The private authoring workspace separately retains historical generator-reference comparisons, standalone service tests, USB profile-switching tests and DVA character-rendering tests. Their external tools, reference catalogues and authoring fixtures are not plugin runtime components and are not required to build this source tree.

The complete original beta14-equivalent build suite was run separately before preparing this public source export. The public source suite is also verified independently. Optical playback, physical USB behaviour and SteamOS controller focus require target-device testing.
