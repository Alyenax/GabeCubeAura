This Lab revision makes the Advanced page easier to scan without changing any
compatibility behaviour.

### Advanced settings

- TW3-SteamRGB compatibility, StripMine compatibility and every
  `Priority while StripMine is active` choice are now hidden behind one toggle.
- The compatibility controls are collapsed by default each time the page is
  opened.
- Expanding them restores the exact same ownership settings, priorities and
  live status information as before.

This remains a private Lab prerelease for target-hardware validation. The
public Stable channel is unchanged.
