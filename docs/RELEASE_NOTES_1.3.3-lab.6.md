This Lab revision makes the brightness recommendation and full-screen setup
navigation clearer.

### First-run setup

- Night brightness now shows its effective `/255` output and the same
  recommended starting value as Day brightness: `9/255`.
- A red warning appears when either Day or effective Night output is below
  `8/255`.
- Every setup step now shows a floating `Scroll down for the buttons` cue above
  Steam's controller footer. The cue disappears when scrolling begins.

This remains a private Lab prerelease for target-hardware validation. The
public Stable channel is unchanged.
