# Optional support block for future release notes

Append this once, after the changes, installation details and known limits:

```markdown
Enjoying GabeCubeAura? A coffee helps me keep experimenting and testing new
ideas: [Support on Ko-fi](https://ko-fi.com/alyenax).
GabeCubeAura stays free and open source. Donations are entirely optional.
```

Release notes are maintained manually in `docs/RELEASE_NOTES_*.md`; there is no
release-note generator to extend. This is a reusable snippet, not a new release
announcement. Existing release notes and published releases are left intact.
