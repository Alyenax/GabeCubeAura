This Lab build moves GabeCubeAura's guided first start to a dedicated
full-screen SteamOS page.

### Full-screen onboarding

- Open the three-step guide from the GabeCubeAura quick panel, then complete
  it in `/gabecubeaura/setup` with the side menu closed.
- Choose Essential, Atmosphere, Immersive or Immersive+ from a
  controller-friendly two-column layout with real 17-LED previews.
- Search for a city manually, configure sunset-to-sunrise brightness and
  review every choice before saving.
- Existing installations still skip onboarding and keep their current
  configuration.

### Update privacy

- Completing or skipping onboarding selects Stable updates with one automatic
  check every 24 hours.
- Any saved Private Lab authorization is removed before setup completes.

This is a private Lab prerelease for target-hardware validation. The stable
public channel remains unchanged.
