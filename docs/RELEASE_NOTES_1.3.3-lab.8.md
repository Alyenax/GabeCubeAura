This Lab revision makes `Skip guided setup` match its visible promise.

### Guided setup

- Choosing `Keep recommended defaults` now explicitly applies Immersive and
  Day brightness `9/255` before onboarding is marked complete.
- The result no longer depends on whatever routing and brightness values were
  present before the first-run screen opened.
- Intentional Valve handoffs still restore the exact saved Steam brightness.

This remains a private Lab prerelease for target-hardware validation. The
public Stable channel is unchanged.
